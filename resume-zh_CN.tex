\section{项目经历}
\datedsubsection{\textbf{毕业设计 | 电解水气泡识别检测模型开发},独立完成}{2025.9 - 2026.6}
\begin{itemize}[parsep=0.05ex]
  \item \textbf{数据集工程：}自建多工况气泡检测/分割数据集（7源170图$\to$\textbf{9524}框），SAM半自动标注，掩码覆盖率\textbf{99.79\%}
  \item \textbf{检测模型：}提出Bubble-YOLO11s——P3LCRefine局部对比度细化（高通滤波+深度可分离卷积+可学习残差）与NWD损失（框建模为二维高斯、平滑小目标梯度）协同CIoU融合，配合Mosaic/HSV/MixUp增强配方，参数仅+\textbf{0.013\%}下S+\textbf{3.94\%}、mAP@50+\textbf{3.42\%}、mAP@50:95+\textbf{4.94\%}
  \item \textbf{分割扩展：}BCE:Dice=9:1混合+SGD零增强，Mask mAP@50=\textbf{0.839}、mAP@50:95=\textbf{0.538}，12轮收敛（较AdamW提速3.8倍）
  \item \textbf{平台闭环：}集成ByteTrack追踪+尺寸量化，KD-Tree/瑞利拟合，输出气泡脱附模式诊断
\end{itemize}
\datedsubsection{\textbf{智训引擎 RSI Harness | 工业模型受控递归自我改进},核心开发}{2026}
\begin{itemize}[parsep=0.05ex]
  \item \textbf{受控 RSI 架构：}将自我改进约束为“诊断归因$\to$实验设计$\to$沙箱执行$\to$门控上线”的闭环；候选超噪声阈值才 promote、劣化超 2$\times$ 阈值回滚，模型始终为官方基线续训 checkpoint，保证平台兼容
  \item \textbf{Agent 内核：}LLM Agent 在 18 个受限工具内自主决定假设、实验与上线，Guard 对全链路动作做约束与审计；停滞时由多角色 Panel 介入并切换探索策略
  \item \textbf{记忆与技能：}有界策展 MEMORY/TASK + SKILL.md 渐进披露 + SQLite/FTS5 经验库，跨轮复用策略胜率与教训；漂移数据流 macro-F1 由 frozen \textbf{0.277} 提升至 \textbf{0.787}
\end{itemize}
